# 신규 인물 25명 공개 전 검토 기록 (2026-09-28)

이 문서는 AI 초안을 검토하면서 확인한 오류와 남은 작업을 기록한다. **배포 승인서가 아니다.** 이 저장소의 `AGENTS.md`와 `docs/인물-추가-절차.md`에 따라 역사적 사실의 최종 대조는 사람이 해야 한다.

## 현재 상태

| 항목 | 확인 결과 |
|---|---|
| 새 인물 | 25명. '빈센트 반고흐'와 '반 고흐'는 한 인물로 처리 |
| 인물별 자료 | `figure.md` 25개, `docs/*.md` 100개, `tests.yaml` 25개 |

| 출처 링크 | 문서 100개 중 63개 `source_url`이 사이트 첫 화면. 해당 주장으로 바로 연결되지 않음 |
| 초상 | 25명 모두 없음. 현재 기본 실루엣 표시 |

| 답변 품질 평가 | 새 인물 25명 모두 평가 기록 없음. 앱 검사 결과 전원 학생 화면에서 숨김 |
| Git | 새 인물 폴더와 조사표가 커밋되지 않은 로컬 파일. 배포 태그 없음 |

## 이번 검토에서 확인하고 고친 주요 오류

- `장영실` 조사표의 한국민족문화대백과사전 링크는 원래 장연군으로 연결됐다. [장영실 항목](https://encykorea.aks.ac.kr/Article/E0048697)으로 바꾸고 출생 연도, 어린 시절 수차 제작담, 측우기 제작 참여의 단정 표현을 뺐다.
- `신사임당`, `이순신`, `태조 이성계` 조사표에도 다른 인물로 연결되는 직접 링크가 있었다. 각각 해당 항목 또는 [과전법 설명](https://contents.history.go.kr/data/pdf/eh/eh_n0380_0010.pdf)으로 바꿨다. 과전법이 농민에게 토지 소유권을 나눠 준 것처럼 쓰인 부분도 바로잡았다.
- `정조`의 '과인은 사도세자의 아들이다'만 따로 제시하던 내용을 [정조실록 즉위년 3월 10일 기사](https://sillok.history.go.kr/popup/viewer.do?id=kva_10003010_004)의 효장세자 후계 설명과 함께 서술했다. 어찰첩 발견만으로 사인을 확정하던 표현을 뺐다.
- `이순신` 명량해전의 133척을 모두 격파했다고 읽힐 문장을 수정했다. [한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0044900)은 조선 전선 13척, 적선 133척과 그중 31척 격파를 전한다.
- `프레데리크 바르톨디`의 어머니 얼굴 모델설과 수에즈 운하 조각상이 자유의 여신상으로 곧바로 바뀌었다는 단정을 뺐다. [미국 국립공원관리청 전기](https://www.nps.gov/stli/learn/historyculture/frederic-auguste-bartholdi.htm)를 기준으로 두 프로젝트를 구분했다.
- `마르쿠스 아우렐리우스`가 매일 밤 촛불 아래 《명상록》을 썼다는 장면과 사인이 확인됐다는 표현을 뺐다. [스탠퍼드 철학백과](https://plato.stanford.edu/entries/marcus-aurelius/)를 참고했다.
- `가우디`의 직접 인용과 어린 시절 장면 중 원문 확인이 되지 않은 내용을 덜어냈다. [사그라다 파밀리아 재단 전기](https://sagradafamilia.org/en/antoni-gaudi)와 [2026년 공사 현황](https://sagradafamilia.org/en/history-of-the-temple)을 참고했다.
- 그 밖에 노벨의 '죽음의 상인' 기사, 모차르트의 확정 사인, 베토벤의 완전 실청, 바흐의 평균율·무명설, 하이든의 교향곡 발명설, 에펠탑 공사 중 사망 사고, 들리브에 대한 차이콥스키의 발언 등에서 단정이나 잘못된 귀속을 수정했다. 각 인물의 조사표에 근거와 보류 이유를 남겼다.

## 공개 전 남은 필수 작업

1. **사람의 사료 대조:** 25명의 본문과 100개 문서에 남은 날짜·수치·고유명사·업적 귀속·따옴표·민감한 주제를 원문과 직접 대조한다. 이번 수정이 모든 문장을 검증했다는 뜻은 아니다. 조사표에도 AI가 작성한 주장과 사이트 첫 화면 링크가 남아 있어 자체적으로 검증 증거가 되지 않는다.
2. **직접 근거 링크:** 사이트 첫 화면만 가리키는 `source_url` 63개를 해당 문서의 주장을 뒷받침하는 구체 페이지로 바꾸거나, 확인할 수 없는 문장을 삭제한다. `source`에 적힌 기관명과 실제 링크가 일치하는지도 확인한다.
3. **저작권과 인용:** 사람이 최종 문구와 출처를 확인한 뒤 `source`, `license_note`, `quotable`을 결정한다. 검토 전 `quotable: true`로 바꾸지 않는다.
4. **초상과 목소리:** 현재 25명 모두 기본 실루엣이다. 초상을 추가할 경우 저장소의 이미지 규칙과 출처 표기를 따른다. 목소리 ID는 형식상 존재하지만 실제 청취 확인이 필요하다.
5. **실제 답변 평가:** 내용 최종 확정 뒤 운영자가 실제 API로 인물별 12문항을 실행하고 사실 오탐 기준을 통과시킨다. 본문 또는 모델에게 전달되는 앞머리가 다시 바뀌면 재평가한다.
6. **배포:** 위 작업과 리뷰를 마친 다음에만 PR, 머지, 태그, 학생 화면 노출을 진행한다.

현재 결과는 **형식상 적재 가능한 AI 교정 초안**이며, 학생 공개용으로 승인된 자료가 아니다.
