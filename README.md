# 세계에 묻다 — 인물 자료

초등 6학년 국어 ‘인물 인터뷰’ 수업 프로그램 **[세계에 묻다](https://github.com/gomgom/ask-the-world)** 가 쓰는 인물 자료입니다.

**여기 적힌 것만이 AI가 “사실”이라고 말할 수 있는 전부입니다.**
자료에 없는 내용을 물으면 AI는 “기억나지 않는다”거나 “자료로는 답할 수 없다”고 답합니다.
지어내지 않습니다.

선생님들의 기여를 환영합니다. 인물 하나를 추가하는 데 필요한 건 마크다운 파일 몇 개뿐입니다.

- **수업에 쓰고 싶은 선생님** → 아래 [수업에 쓰는 방법](#수업에-쓰는-방법)
- **인물 자료를 보태고 싶은 선생님** → [자료를 보내는 방법 (PR)](#자료를-보내는-방법-pr)
- **AI로 자료를 만드는 분** → 먼저 [AGENTS.md](AGENTS.md) 를 AI에게 읽혀 주세요

## 수업에 쓰는 방법

주소는 **[인터뷰.쌤.한국](https://인터뷰.쌤.한국)** 입니다. 학생은 가입하지 않습니다. 선생님만 가입해 **수업 코드**를 만들어 칠판에 적어 주면 됩니다.

### 1. 선생님 가입

1. [인터뷰.쌤.한국/teachers](https://인터뷰.쌤.한국/teachers) 에서 **가입하기**
2. **시도교육청 공직자 통합메일**(예: `○○○@sen.go.kr`)만 가입할 수 있습니다. 받은 인증 메일의 링크를 누르면 가입이 끝납니다
3. 계정과 자료는 **매년 2월 말에 한꺼번에 지워집니다**(새 학년도에 다시 가입)

### 2. AI 쓰는 방법 고르기 — 무료 체험 또는 내 AI 키

수업 코드를 만들려면 둘 중 하나가 있어야 합니다.

| | 무료 체험 | 내 AI 키 |
|---|---|---|
| 무엇 | 운영자가 비용을 내는 체험분 | 선생님이 직접 받은 AI 키 |
| 양 | 한 학급분 (약 210질문 = 30명 × 7질문) | 키에 충전한 만큼 |
| 비용 | 없음 | 질문 1개에 약 1원 (Claude Haiku 기준 — 30명 × 7질문 ≈ 200원) |
| 신청 | 아래 "무료 체험 신청" | 아래 "Anthropic 키 받기" (추천) |

#### 무료 체험 신청

1. 선생님 화면의 **🎁 무료 체험** 칸에 학교 이름과, 원하면 어떤 수업에 쓰실지 한 줄을 적고 **체험 신청**
2. 운영자(곰곰쌤)가 확인해 승인합니다. 결과는 같은 화면에 뜹니다 (보통 하루 안)
3. 승인되면 수업 코드를 만들 때 **"무료 체험"** 을 고르면 됩니다. 다 쓰면 내 AI 키로 이어 쓰실 수 있습니다

#### Anthropic(Claude) 키 받기 — 추천

가입만 하면 키를 바로 받을 수 있어 가장 쉽습니다. 학생 수업에 쓸 수 있습니다.
(화면 이름은 Anthropic 사정에 따라 조금 바뀔 수 있습니다.)

1. **[console.anthropic.com](https://console.anthropic.com)** 에서 가입합니다 (이메일 또는 Google 계정)
2. **Billing(결제)** 에서 카드를 등록하고 **크레딧을 충전**합니다. 가장 적은 금액(몇 달러)으로도 여러 학급이 충분히 씁니다
3. **Limits(한도)** 에서 **월 사용 한도**를 낮게 걸어 두세요. 예상보다 많이 나가는 일을 막는 가장 확실한 방법입니다
4. **API Keys** 에서 **Create Key** → 나온 키(`sk-ant-…`)를 **복사**합니다. 이 키는 한 번만 보이니 바로 붙여 넣으세요
5. 선생님 화면 **🔑 내 AI 키** → **Claude (Anthropic)** 칸에 붙여 넣고 보관 기간(최장 30일)을 골라 저장합니다

- 키는 암호화해 보관하고, 정한 기간이 지나면 저절로 지워집니다. 화면에는 앞뒤 몇 글자만 보입니다
- 키를 남에게 보여 주거나 칠판·문서에 적지 마세요. 새어 나가면 Anthropic 콘솔에서 그 키를 지우고 새로 만드세요
- 이 키로 만든 수업 코드는 그 선생님과 Anthropic 사이의 이용 관계입니다. Anthropic 이용 정책도 함께 지켜 주세요
  ([개인정보처리방침 제6조](https://gomgom.net/privacy/#teacher-key))

> Google 키(Vertex AI · AI Studio)로는 **Gemini** 를 씁니다. Vertex 는 서비스 계정·권한 설정이 필요하고,
> **AI Studio 키는 선생님 본인 시험용**입니다 — 약관상 18세 미만이 쓰는 수업에 쓸 수 없습니다.

### 3. 수업 코드 만들기

1. **🎟 수업 코드 만들기** 에서 어떤 AI로 대답할지(무료 체험·내 키) 고릅니다
2. 코드를 쓸 기간(기본 8시간, 최장 30일), 추천 질문·소리로 듣기를 정하고, 안내를 읽은 뒤 동의 체크 → **만들기**
3. 나온 한글 코드(예: `파란하늘381`)를 칠판에 적거나 **📺 학생에게 크게 보여 주기** 로 띄웁니다

### 4. 학생 활동

1. 학생은 **인터뷰.쌤.한국** 에 들어와 기기(학교 공용 / 내 기기)를 고르고 수업 코드를 넣습니다
2. 인물을 골라 질문합니다. 학생 한 명이 하루에 모든 인물을 합쳐 **10개**까지 물을 수 있습니다
3. 대답의 문장마다 점이 붙습니다 — **■ 사실**(눌러서 원문 확인) · **◇ 추정** · **☐ 기억이 흐림**. 이것을 구분하는 것이 수업의 핵심입니다
4. 인터뷰를 **A4로 인쇄**해 손글씨로 기사를 씁니다
5. 이상한 대답은 🚩 **신고**로 선생님께 알릴 수 있습니다 (선생님 화면에서 14일 동안 보입니다)

어떤 AI로 도는 수업이냐에 따라 아직 그 AI로 평가되지 않은 인물은 **흐리게 보이고 고를 수 없습니다.**
모든 인물을 쓰시려면 Claude(Anthropic 키나 무료 체험)를 고르세요.

## 인물 하나 추가하기

> 처음부터 끝까지의 순서와 실제로 걸렸던 것들은
> **[docs/인물-추가-절차.md](docs/인물-추가-절차.md)** 에 있습니다. 여기는 파일 형식입니다.

### 1. `figure.md` — 인물 설정집

```yaml
---
id: mandela                     # 폴더 이름과 같게
name_ko: 넬슨 만델라
name_en: Nelson Mandela
lifespan: "1918–2013"
living: false                   # ⚠️ 생존 인물은 아래 '생존 인물' 절을 꼭 읽으세요
one_liner: 남아프리카공화국의 인권 운동가이자 첫 흑인 대통령
era_context: 백인과 흑인을 법으로 갈라놓았던 아파르트헤이트 시대
knowledge_cutoff: "2013-12-05"  # 이 뒤의 일은 모릅니다
grade_level: 6

starter_questions:              # 브리핑 화면의 예시 질문
  - 어릴 때는 어떤 아이였나요?

values:                         # 짐작해서 답할 때의 근거가 됩니다
  - 미움이 아니라 용서로 나라를 하나로 만든다

speech_style:                   # 설명보다 예시가 훨씬 잘 먹힙니다
  - 천천히, 낮고 차분한 목소리로 이야기합니다

sample_lines:                   # 실제로 이렇게 말한다는 본보기 3~5개
  - 미움은 배워서 생기는 것입니다. 배울 수 있다면, 사랑도 배울 수 있지요.

sensitive_topics:               # 조심해서 다뤄야 할 주제와 지침
  - topic: 감옥에서 겪은 고통
    guidance: 사실만 담담하게. 폭력의 자세한 묘사는 하지 않는다.

era_label: 20세기 남아프리카      # 인물 고르는 화면의 시대 꼬리표 (선택, 12자 이내)
category: 나라와 평화            # ⭐ 필수. 인물 고르는 화면의 분야 묶음 — 아래 여섯 중 하나
                                #    지도자 · 나라와 평화 · 과학과 발명 · 음악 · 미술과 건축 · 철학과 문학
greeting: 반가워요. 저는 넬슨 만델라입니다.   # 채팅을 열면 먼저 건네는 인사 (선택)
                                # ⚠️ AI 가 아니라 이 문장이 그대로 나옵니다. 근거 점이
                                #    붙지 않으니 연도·숫자 같은 사실은 넣지 마세요 (검사가 막습니다)
voice: ko-kr-tutor-1            # ⭐ 필수. 소리로 듣기 목소리 — 아래 "목소리 정하기"
voice_style: "나이 지긋한 어른처럼 천천히 낮고 따뜻하게"   # ⭐ 필수. 말투 지시 (60자 이내)
                                # ⚠️ 여성 인물은 voice 를 꼭 적으세요 — 기본 목소리는 남성입니다.
                                #    실제 인물의 목소리를 흉내 내라고 쓰지 마세요. 말투만 정합니다.

portrait: portrait.webp         # 초상 그림 (선택). 없으면 기본 실루엣
portrait_credit: "생성형 AI로 만들어진 일러스트 (2026)"   # 화면에 밝힐 출처
photo: photo.jpg                # 퍼블릭 도메인 사진 (선택). 소개 화면에만
photo_credit: 1910년 촬영 · 퍼블릭 도메인   # photo 가 있으면 **필수**
photo_source_url: https://...   # 있으면 출처에 링크가 걸립니다
---

## 어떤 사람이었나

(학생에게 보여 줄 소개. 초6이 읽을 수 있는 말로.)

## 학생에게 어떻게 말할 것인가

(AI에게 주는 지침. **이 절부터는 학생 화면에 나오지 않습니다.**)
```

> 첫 번째 `##` 절만 학생 브리핑에 나갑니다. 그 뒤는 AI·교사용 지침입니다.

### 2. `docs/*.md` — 자료 문서

AI가 “사실”이라고 말할 때 근거로 대는 것들입니다.

kind: timeline                  # biography | timeline | speech | letter | interview | event | teacher_summary
summary: 태어난 해부터 세상을 떠날 때까지의 주요 사건.

source_url: ""
quotable: true                  # ⚠️ 저작권 판단입니다. 아래를 꼭 읽으세요

## 인물 그림 넣기

`figures/<인물>/` **안에** 이미지를 넣고 `figure.md` 에 파일 이름을 적습니다.

```
figures/ahn-jung-geun/
  figure.md
  portrait.webp     ← 채팅 아이콘·목록·소개에 다 쓰입니다
  photo.jpg         ← 소개 화면에만 (선택)
  docs/
```

> 💥 **`figures/` 바로 밑에 폴더를 만들면 안 됩니다.** 검사 프로그램이 거기 있는
> 폴더를 전부 인물로 보기 때문에, `figures/그림/` 같은 것을 만들면
> `figure.md 가 없습니다` 로 검사가 통째로 실패합니다.

### 그림은 새로 그리세요. 사진을 옮기지 마세요

**사람의 얼굴에는 저작권이 없습니다. 그 얼굴을 찍은 사진에는 있습니다.**
그래서 `안중근을 그려 줘` 는 괜찮고 `이 사진 그대로 만화로` 는 위험합니다.
AI 로 만드실 때도 **특정 사진을 참고 이미지로 넣지 마세요.**

사진처럼 사실적인 그림은 피해 주세요. 이 앱은 화면마다
*"진짜 ○○이 아니에요"* 라고 말합니다. 그림은 그 자체로 "이건 묘사예요" 를
담고 있어 그 말과 같은 편이 되지만, 사진 같은 그림은 반대로 말합니다.

### 퍼블릭 도메인 사진

`photo` 를 쓰려면 `photo_credit` 이 **반드시** 있어야 합니다. 없으면 검사가 막습니다.
`quotable: true` 인 문서에 `source` 를 요구하는 것과 같은 규칙입니다 —
**출처를 못 밝히는 것은 쓰지 않습니다.**

한국 저작권법에서 **1977년 이전에 창작된 사진**은 보호 기간이 끝났습니다.
그보다 뒤의 사진은 위키미디어 공용에서 CC 라이선스를 확인하고,
`photo_credit` 에 촬영자와 라이선스를 적어 주세요.

## 목소리 정하기 (필수)

학생이 **소리로 듣기**를 켜면 인물의 답을 목소리로 읽습니다. 그래서 `figure.md` 에
`voice` 와 `voice_style` 이 **반드시** 있어야 합니다. 없으면 형식 검사가 막습니다.

```yaml
voice: ko-kr-tutor-1
voice_style: "지난 삶을 돌아보며 손주에게 이야기하듯, 나이 지긋한 어른의 목소리로 천천히 낮고 따뜻하게."
```

## ⚠️ 따옴표는 "원문을 봤다"는 선언입니다

`quotable` 이 **"옮겨도 되는가"(저작권)** 라면, 따옴표는 **"정말 그렇게 적혀
있었는가"(진위)** 입니다. 둘은 다른 질문이고, **이 앱은 진위를 검사하지 않습니다.**

서버는 AI 가 댄 인용문이 자료에 있는지만 봅니다. 자료가 참인지는 아무도 안 봅니다 —
자료를 사람이 사료를 보고 쓴다는 전제이기 때문입니다.

그래서 **확인하지 않은 말은 따옴표에 넣지 마세요.** 풀어서 쓰면 됩니다.

```markdown
✗ 안중근은 "만국공법에 항복한 포로는 죽이지 못한다"라고 말했습니다.
✓ 안중근은 만국공법에 따라 포로를 죽일 수 없다며 동료들을 설득했습니다.
```

원문을 직접 확인하셨다면 앞머리에 적어 주세요:

```yaml
quotes_verified: true
```

25자가 넘는 따옴표가 있는데 이 값이 없으면 검사가 경고합니다. 막지는 않습니다.

> **AI 에게 자료를 맡기실 때는 [AGENTS.md](AGENTS.md) 를 함께 읽히세요.**
> AI 는 그럴듯한 말을 따옴표에 넣는 일을 아주 잘합니다. 형식 검사는 그걸 못 잡습니다.

## ⚠️ `quotable` 은 저작권 판단입니다

| 값 | 뜻 |
|---|---|
| `false` | 근거로는 쓰이되, **큰따옴표 직접 인용이 서버에서 걷힙니다.** 내용만 풀어서 설명합니다 |
| `true` | AI가 원문을 그대로 인용할 수 있습니다 |

**출처를 확인하지 않았다면 반드시 `false` 로 두세요.** 기본값이 아니라 판단입니다.

- 저작권이 살아 있는 전기·번역서 **본문을 옮겨 담지 마세요.**
- 선생님이 직접 쓴 요약, 공공 영역 원문, 정부·공공기관 공개 자료만 씁니다.
- `quotable: true` 로 두려면 `source` 에 근거를 반드시 적어야 합니다 (CI가 확인합니다).

## 자료를 보내는 방법 (PR)

### PR(풀 리퀘스트)이 뭔가요?

**"제가 이렇게 고쳐 봤는데, 원본에 반영해 주세요"** 하고 보내는 **수정 제안서**입니다.
보낸다고 바로 바뀌지 않습니다. 관리자가 읽어 보고 **승인(머지)** 해야 원본에 들어갑니다.
무엇을 바꿨는지 한 줄 한 줄 비교해서 볼 수 있어, 여러 사람이 함께 자료를 고치기에 좋습니다.

### 보내는 순서 (웹 브라우저만으로)

1. **GitHub 가입** — [github.com](https://github.com) 에서 무료로 가입합니다
2. **포크(Fork)** — 이 저장소 오른쪽 위 **Fork** 를 누르면 내 계정에 복사본이 생깁니다
3. **파일 넣기** — 내 복사본에서 `figures` 폴더로 들어가 **Add file → Create new file**(새로 쓰기) 또는 **Upload files**(파일 올리기)
   - 새 인물은 `figures/<영문-이름>/figure.md` 처럼 **경로째** 적으면 폴더가 함께 만들어집니다
   - 형식은 아래 [인물 하나 추가하기](#인물-하나-추가하기)와 본보기 `figures/mandela/` 를 따라 주세요
4. **저장(Commit changes)** — 무엇을 했는지 한 줄 적고 저장합니다
5. **PR 보내기** — 위쪽에 뜨는 **Contribute → Open pull request** 를 누르고, 무엇을 왜 바꿨는지와 **어느 자료(책·사료·기관 페이지)를 보고 썼는지** 적어 보냅니다
6. **자동 형식 검사** — PR 화면에 검사 결과가 뜹니다. ❌ 이면 무엇이 틀렸는지 적혀 있으니 같은 PR 에서 고치면 됩니다

### 보낸 뒤에는 — 관리자가 검토하고 승인한 뒤 배포합니다

```
PR 보냄 → 자동 형식 검사 → 관리자 검토(사실·출처·저작권) → 승인(머지)
       → 관리자가 답변 품질 평가 → 새 버전(태그) → 앱에 자동 배포 → 학생 화면에 나타남
```

- **형식 검사 통과는 "내용이 맞다"는 뜻이 아닙니다.** 사실 확인은 관리자가 따로 합니다. 고칠 점이 있으면 PR 에 댓글로 묻습니다
- 승인돼도 **답변 품질 평가를 통과해야** 학생 화면에 나옵니다. 평가 전인 인물과, 평가 뒤 내용이 바뀐 인물은 자동으로 숨겨집니다
- 머지만으로는 앱이 바뀌지 않습니다. 관리자가 새 버전을 낼 때 함께 나갑니다 — **수업 중에 자료가 갑자기 바뀌지 않게** 하려는 장치입니다
- 보낸 자료는 이 저장소의 라이선스(CC BY-SA 4.0)로 공개됩니다

GitHub 가 어려우시면 곰곰쌤(contact@gomgom.net)에게 파일을 보내 주셔도 됩니다.

AI 로 자료를 만들었다면 **반드시** [AGENTS.md](AGENTS.md) 를 먼저 AI 에게 읽히고, AI 가 넘겨준 "사람이 확인할 목록"을
직접 확인한 뒤 보내 주세요. 자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md) 에 있습니다.
