# 세계에 묻다 — 인물 자료

초등 6학년 국어 ‘인물 인터뷰’ 수업 프로그램 **[세계에 묻다](https://github.com/gomgom/ask-the-world)** 가 쓰는 인물 자료입니다.

**여기 적힌 것만이 AI가 “사실”이라고 말할 수 있는 전부입니다.**
자료에 없는 내용을 물으면 AI는 “기억나지 않는다”거나 “자료로는 답할 수 없다”고 답합니다.
지어내지 않습니다.

선생님들의 기여를 환영합니다. 인물 하나를 추가하는 데 필요한 건 마크다운 파일 몇 개뿐입니다.

---

## 폴더 구조

```
figures/
  mandela/
    figure.md          ← 인물의 성격·말투·가치관 (항상 AI에게 전달됨)
    docs/
      01-timeline.md   ← 자료 문서. AI가 근거로 인용합니다
      02-early-life.md
      …
    tests.yaml         ← 답변 품질 검사 질문 12개
```

폴더 이름(`mandela`)과 `figure.md` 의 `id:` 는 **똑같아야** 합니다.

## 인물 하나 추가하기

### 1. `figure.md` — 인물 설정집

```yaml
---
id: mandela                     # 폴더 이름과 같게
name_ko: 넬슨 만델라
name_en: Nelson Mandela
lifespan: "1918–2013"
living: false                   # ⚠️ 생존 인물은 아래 '생존 인물' 절을 꼭 읽으세요
one_liner: 남아프리카공화국의 인권 운동가이자 첫 흑인 대통령
era_context: 백인과 흑인을 법으로 갈라놓았던 아파르트헤이트 시대
knowledge_cutoff: "2013-12-05"  # 이 뒤의 일은 모릅니다
grade_level: 6

starter_questions:              # 브리핑 화면의 예시 질문
  - 어릴 때는 어떤 아이였나요?

values:                         # 짐작해서 답할 때의 근거가 됩니다
  - 미움이 아니라 용서로 나라를 하나로 만든다

speech_style:                   # 설명보다 예시가 훨씬 잘 먹힙니다
  - 천천히, 낮고 차분한 목소리로 이야기합니다

sample_lines:                   # 실제로 이렇게 말한다는 본보기 3~5개
  - 미움은 배워서 생기는 것입니다. 배울 수 있다면, 사랑도 배울 수 있지요.

sensitive_topics:               # 조심해서 다뤄야 할 주제와 지침
  - topic: 감옥에서 겪은 고통
    guidance: 사실만 담담하게. 폭력의 자세한 묘사는 하지 않는다.
---

## 어떤 사람이었나

(학생에게 보여 줄 소개. 초6이 읽을 수 있는 말로.)

## 학생에게 어떻게 말할 것인가

(AI에게 주는 지침. **이 절부터는 학생 화면에 나오지 않습니다.**)
```

> 첫 번째 `##` 절만 학생 브리핑에 나갑니다. 그 뒤는 AI·교사용 지침입니다.

### 2. `docs/*.md` — 자료 문서

AI가 “사실”이라고 말할 때 근거로 대는 것들입니다.

```yaml
---
doc_id: mandela-timeline        # 저장소 전체에서 겹치지 않게
title: "넬슨 만델라 연표"
kind: timeline                  # biography | timeline | speech | letter | interview | event | teacher_summary
summary: 태어난 해부터 세상을 떠날 때까지의 주요 사건.
source: "교사가 정리한 연표 (널리 알려진 공개 사실)"
source_url: ""
quotable: true                  # ⚠️ 저작권 판단입니다. 아래를 꼭 읽으세요
---

1918년 7월 18일, 남아프리카 트란스케이의 음베조 마을에서 태어났다.
```

### 3. `tests.yaml` — 품질 검사 질문 12개

`figures/mandela/tests.yaml` 을 본보기로 삼으세요. 6가지 유형 × 2문항입니다.
특히 **⑤ 함정(자료에 없는 구체적 숫자를 묻기)** 을 꼭 넣어 주세요.
AI가 숫자를 지어내는지 확인하는 문항입니다.

---

## ⚠️ `quotable` 은 저작권 판단입니다

| 값 | 뜻 |
|---|---|
| `false` | 근거로는 쓰이되, **큰따옴표 직접 인용이 서버에서 걷힙니다.** 내용만 풀어서 설명합니다 |
| `true` | AI가 원문을 그대로 인용할 수 있습니다 |

**출처를 확인하지 않았다면 반드시 `false` 로 두세요.** 기본값이 아니라 판단입니다.

- 저작권이 살아 있는 전기·번역서 **본문을 옮겨 담지 마세요.**
- 선생님이 직접 쓴 요약, 공공 영역 원문, 정부·공공기관 공개 자료만 씁니다.
- `quotable: true` 로 두려면 `source` 에 근거를 반드시 적어야 합니다 (CI가 확인합니다).

---

## ⚠️ 생존 인물

`living: true` 로 두면 규칙이 자동으로 엄격해집니다 — 짐작해서 답하기 금지,
정치적 견해·타인 평가 거절.

**살아 있는 사람이 하지 않은 말을 지어내는 것은 그 사람에게 실제로 해가 됩니다.**
당분간은 세상을 떠난 인물만 받습니다. 현대 인물을 원하시면
스티븐 호킹(2018), 이태석 신부(2010)처럼 **최근에 돌아가신 분**이 좋은 절충입니다.

## 자료를 고르는 기준

- **분량**: 인물당 A4 12쪽(약 25,000토큰) 이내. 넘으면 CI가 경고합니다.
- **초6이 읽을 수 있는 말로.** 어려운 낱말은 괄호로 풀어 주세요.
- **민감한 주제를 피하지는 마세요.** 대신 `sensitive_topics` 에 다루는 방법을 적어 주세요.
  전쟁·죽음·차별은 위인의 삶에서 빼놓을 수 없습니다.
- 당시에 쓰인 차별 표현이나 멸칭은 **절대 그대로 옮기지 마세요.**

## 기여하기

1. 이 저장소를 포크하고 `figures/<인물>/` 을 추가합니다
2. PR 을 올립니다 — CI 가 형식을 자동으로 검사합니다
3. 머지된 뒤, 운영자가 답변 품질 검사(`npm run eval`)를 돌리고 **새 태그를 찍으면** 앱에 반영됩니다

> 머지만으로는 앱이 바뀌지 않습니다. **수업 중에 자료가 갑자기 바뀌지 않게** 하려는 장치입니다.

자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md) 를 봐 주세요.
